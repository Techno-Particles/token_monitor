# Change Log

All notable changes to the ai-usage-monitor extension will be documented in this file.

## [0.1.0] - Unreleased

- Added privacy-first local Codex live usage tracking with status-bar and dashboard views.
- Added authoritative total processing, fresh-input, cached-input, output, reasoning, and cache-rate analytics.
- Added Today, Last 7 days, Last 30 days, and All time history with 7-day and 30-day charts.
- Added model and project/workspace usage breakdowns.
- Added provider-reported 5-hour and weekly limit windows with reset countdowns.
- Added reset-aware observed limit burn-rate analytics without allowance or exhaustion predictions.
- Added safe Claude Code and Gemini CLI detection foundations without claiming unverified token tracking.
- Added bounded, local-only normalized history and rate-limit observation storage with privacy safeguards.
